# sh, bash

- Переменные - в виде `UPPER_CASE`.
- Стандартная шапка, если не требовалось иное:
  ```
  #!/bin/bash
  
  set -euo pipefail
  
  (дальше идёт тело скрипта)
  ```
- для создания временных файлов - конструкция примерно в начале файла вида:
  ```
  TEMP_FILE=""
  cleanup() {
    local FILE
    if [ -z "${NO_CLEANUP:-}" ]; then
      for FILE in "$TEMP_FILE"; do
        [ -n "${DEBUG:-}" ] && echo "$0: cleanup(): rm -f $FILE"
        rm -f "$FILE"
      done
    fi
  }
  trap cleanup EXIT

  ...
  TEMP_FILE="$(mktemp [./data/].tmp.prefix.XXXXXXXX)"
  ```
  Не буквально (например, тут под [./data/] имеется в виду - добавлять каталог, если мы с данными работаем в нём)
  Если переменных несколько - по аналогии, добавляя в цикл for.
  Если будут tempdir, то добавить по аналогии отдельный for, в котором будет rm -rf.
- Язык для всего кода (в т.ч. комментариев) - английский. Без изысков, сухо, коротко. Не транслит! А именно английский!
